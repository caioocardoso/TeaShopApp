# 🍃 Tea Shop App

> Um aplicativo elegante e intuitivo para os amantes de chá, desenvolvido em React Native.

Este projeto consiste em um aplicativo móvel para uma loja virtual de chás, focado em proporcionar uma experiência de compra fluida, visualmente atraente e relaxante para o usuário.

---

## 🚀 Status do Projeto

⚠️ **Em Desenvolvimento** O projeto está sob desenvolvimento ativo. Novas funcionalidades, melhorias de UI e atualizações de código serão implementadas e documentadas continuamente. Fique atento às próximas novidades!

---

## 🛠️ Tecnologias Utilizadas

O ecossistema principal do app conta com:

* **React Native** — Framework para desenvolvimento cross-platform (iOS/Android).
* **TypeScript** — Tipagem estática para um código mais seguro, limpo e livre de erros.
